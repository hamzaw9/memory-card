# 📖 Memory Game <a name="about-project"></a>

This is a **memory game** built with **React (TypeScript)**, **Vite**, and **Tailwind CSS**. It demonstrates core React concepts like *state management* and *lifting state up*.

## 🎮 Game Rules

- A set of images is displayed to the user.
- Each time the user clicks on a **new image**, their **score increases**.
- If the user clicks the **same image twice**, the **game ends** and the **score resets**.
- The images are **shuffled** after every correct click to increase difficulty.
